PNG and WebP exports use a row-major grid. Animation exports include sampled cardinal poses and, by default, eight additional still views at the missing 30° angles, sampled from the selected clip at time 0. Eight shear/rotation-derived animation directions are optional and off by default; blended playback frames are excluded. WebP uses adaptive palette reduction to at most 256 colors, then lossless encoding, with sprite metadata embedded as XMP. Model size is the selected file size; external files referenced by a .gltf are not included.
